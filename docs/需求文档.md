## 一、项目概述

### 1.1 项目名称

智能课表打铃（代号 KeRing）

### 1.2 项目背景

教室一体机、会议室大屏、办公室固定 PC 等固定设备，需要按最新课表自动、准时地语音提醒。
现状靠人工或独立打铃器，无法与动态课表联动。

### 1.3 项目目标

做一个免安装、开机自启、托盘常驻、无黑框、能看周课表、能按课表定时播报的 Windows 桌面程序。

注意本程序只负责**课前提醒**这一种播报；上课铃、下课铃等其他播报由使用方已有的程序负责。

### 1.4 目标用户

教室管理员 / 教务人员。使用者（老师、学生）不接触本软件，只听到声音，
所以"响错了"的代价远高于"界面丑"。

### 1.5 部署场景

- 教室一体机、大屏主机（Windows 10/11，x64），长期通电
- 每天放学后关机，第二天开机
- 机器已开启自动登录

### 1.6 部署前置条件（必须由使用方保证）

| # | 条件 | 不满足会怎样 |
| --- | --- | --- |
| C1 | 目标机开启自动登录，运行期间不注销、不切换用户 | 无人登录时 `HKCU\Run` 自启项不执行，程序根本不启动。锁屏、息屏没关系，注销等于杀掉会话 |
| C2 | 目标机装有 .NET Framework 4.7.2 或更高 | Win10 1803 以后和 Win11 自带；Win7 需要装一次 |
| C3 | 系统已安装中文语音包（zh-CN） | TTS 无中文音色，播报静默无声 |
| C4 | 有可用的音频输出设备 | 播报没有声音 |
| C5 | 系统时间已同步（NTP 或域时间） | 打铃整体错位 |

## 三、数据接口约定

程序不关心课表怎么抓、怎么解析，只约定拿到什么结构的数据。

### 3.1 获取方式

由使用方提供的接口获取，程序定时调取并解析。**具体规则与参考示例由使用方提供，待定**（见 §12）。

当前骨架用一个本地 JSON 文件代替这个接口（演示用，正式以使用方规则为准）：

```json
{
  "generated_at": "2026-09-13T17:42:00+08:00",
  "periods": [
    { "index": 1, "start": "08:00", "end": "08:45" },
    { "index": 2, "start": "08:55", "end": "09:40" }
  ],
  "entries": [
    { "weekday": 1, "period": 1, "course": "语文" },
    { "weekday": 1, "period": 2, "course": "数学" }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| periods | 节次编号（第几节）。注意：**具体时刻不采用数据里的 start/end**，而是由本机的作息方案（低年级/高年级，见 F25）决定——数据源不知道这台机器属于哪个年级 |
| entries | 课程落在星期几的第几节；course 为空表示空堂 |

换句话说：**课表数据负责"第几节上什么课"，作息时间负责"第几节是几点"。** 两者分开，同一份课表数据可以发给低年级和高年级两种教室，只要各机器上的方案设对即可。

### 3.2 接入方式

程序内部以 `IScheduleSource` 为界：实现一个类把"取数 + 解析"都放进去，其余代码（打铃点生成、调度、播报、界面）不用动。

### 5.1 为什么是 .NET Framework 4.7.2 而不是 .NET 8/10

- Windows 自带的是 .NET Framework（4.7.2 / 4.8），**不包含** .NET 8/10；用新版就得自包含，体积从 620 KB 涨到 52 MB
- .NET 8 及以上完全不支持 Windows 7；4.7.2 兼容到 Win7（需装一次）
- 定 4.7.2 而不是 4.8：4.7.2 的程序在 4.8 机器上照样跑，反过来不行。Win10 1809 LTSC 这类一体机常见系统自带 4.7.2，定低一档覆盖更广
- 代价：生态偏旧、少数新语法要垫片；本项目的需求用不到新特性

### 5.2 实测数据（2026-09-13）

| 项目 | 结果 |
| --- | --- |
| 编译 | net472 + WinForms + System.Speech + NAudio，0 警告 0 错误 |
| 体积 | 主程序 40 KB + 依赖约 1.27 MB（其中 Newtonsoft.Json 占 695 KB） |
| 音频链路 | 播报前音量 25% → 播报（提示音 + 语音）→ 播报后恢复 25% |
| 中文音色 | 本机 1 个（Microsoft Huihui） |

### 5.3 已知技术风险

| 风险 | 应对 |
| --- | --- |
| 中文音色缺失 | 自检检查；缺了播报会没声音，必须能被发现（F18） |
| 目标机没有 4.7.2 | 准备离线安装包，装机时装一次；Win7 还需先打 SHA-2 补丁 |
| 定时器漂移 | 已规避：不累加间隔，每次按系统时钟重算 |
| 音频被独占 | 播报失败要能被发现（F23） |
| 杀软误报 | 用代码签名证书，而不是靠打包方式 |
| 高分屏模糊 | 已设置 DPI 感知 |

## 六、系统架构

```
表现层  UI/MainForm.cs                     周课表 + 状态栏 + 托盘 + 触发播报
─────────────────────────────────────────────
业务层  App/Scheduler.cs                   1 秒轮询、跨天重建、触发提醒
        App/Schedule/ReminderPlanner.cs    课表 → 打铃点
        App/Audio/Announcer.cs             提示音 + 语音 + 音量临时提升/恢复
─────────────────────────────────────────────
基础层  App/Schedule/ScheduleSource.cs     IScheduleSource（取数 + 解析）
        App/Audio/AudioController.cs       系统音量
        App/Audio/BellTone.cs              提示音文件
        App/AppConfig.cs / AppPaths.cs / Logger.cs / AutoStart.cs
```

分层原则：打铃点生成与调度不依赖界面类型，系统时间可注入，便于单元测试。

## 七、关键流程

### 7.1 启动

1. 检查单实例（Mutex）；已有实例则通知它显示窗口后退出
2. 设置 DPI 感知，初始化 WinForms
3. 读配置（首次运行生成默认配置）
4. 打开托盘图标，加载课表并生成当天打铃点
5. 启动调度器与界面刷新，显示主窗口（或按配置最小化到托盘）

### 7.2 打铃

1. 调度器每秒醒来，读系统时间
2. 匹配当天未触发、且时间已到的打铃点
3. 播报前把系统音量临时提升到设定值并解除静音
4. 播放提示音，再朗读「下节课，{课程名}，请同学们做好课前准备」
5. 恢复原音量与原静音状态
6. 标记已触发；跨天则重建当天打铃点

程序启动前或重启期间已经过去的打铃点不补播，只记日志。

### 7.3 更新

1. 定时或手动触发
2. 从数据源取数并解析
3. 成功则刷新界面 + 重建打铃点；失败则保留上一次有效课表，状态栏提示并记日志

## 十、风险与应对

| 风险 | 应对 |
| --- | --- |
| 数据源失效 | 保留上次有效课表 + 状态提示 + 日志（F22） |
| 目标机没有 4.7.2 / 中文语音包 | 装机检查清单 + 离线安装包 |
| 目标机未自动登录 | 前置条件 C1，验收时按"开机后未人工登录"路径验证 |
| 被误关 | 托盘常驻 + 退出走托盘菜单 |
| 音色缺失导致无声 | 自检 + 状态提示 |
| 杀软误报 | 代码签名 |

不覆盖：系统睡眠、断电、重启导致的漏播——评审确认机器不会睡眠，漏播不做检测。

## 十一、不在范围内（Out of Scope）

评审确认**不做**的，写在这里避免后续反复讨论：

| 不做 | 原因 |
| --- | --- |
| 上课铃、下课铃、其他播报 | 由使用方已有程序负责 |
| 手动打铃 | 同上，其他铃不归本程序管 |
| 多铃型映射（眼保健操、大课间等） | 同上 |
| 防系统睡眠 | 机器不会睡眠 |
| 漏播检测与告警 | 同上，评审决定不做 |
| 数据有效期 / 过期保护 | 断网场景不考虑，假期机器关机 |
| 假期与调课的特殊处理 | 假期机器关机，不涉及 |
| 数据变化检测（哈希比对） | 数据源本地、刷新成本低，暂不需要 |
| 手动导入课表 | 走数据源，暂不需要 |
| 独立配置界面 | 配置就是一个 JSON 文件，手工改 |
| 界面锁定 / 密码退出 | 暂不需要 |
| 全屏大屏视图 | 窗口是给管理员看的工具，不是展示屏 |
| 崩溃自恢复 / 看门狗 | 每天开机启动一次，异常由人发现即可 |
| 系统时间偏差检查 | 机器时间由学校统一同步 |
| 程序自更新 | 第一版手工替换文件夹 |
| 课表抓取与解析规则本身 | 由使用方提供接口 |
| 请假、考勤、点名 | 与本项目目标无关 |
| 手机端 / 网页端 | 本程序是常驻桌面工具 |
| 多机状态同步 | 复杂度高，不需要 |
| 非 Windows 平台 | 部署环境就是 Windows |
