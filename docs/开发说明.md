# KeRing 开发说明

智能课表打铃。当前是**可运行的骨架版**，功能按评审通过的约定实现，数据接口按正式规则接入即可。

## 环境

| 项目 | 说明 |
| --- | --- |
| 目标框架 | .NET Framework 4.7.2（Win10 1803 以后 / Win11 自带，Win7 装一次） |
| 语言版本 | `<LangVersion>latest</LangVersion>`（不设会退回 C# 7.3，模板写法直接编不过） |
| 依赖 | NAudio 2.2.1（音量、播放）、Newtonsoft.Json 13.0.3（配置、课表） |
| 系统引用 | `System.Speech`（框架自带，不是 NuGet 包） |
| IDE | VS Code 或 Visual Studio。界面是代码构建的，没有 .Designer.cs |

## 编译与运行

```
dotnet build -c Release
bin\Release\net472\KeRing.exe
```

## 自检

不带界面，直接在目标机上跑一遍：

```
KeRing.exe --selftest
```

检查配置、课表、打铃点、音频设备、中文音色、提示音文件、自启状态，返回码为问题数（0 = 通过）。

## 目录结构

```

UI/MainForm.cs            主界面：周课表 + 状态栏 + 托盘 + 播报

UI/UiScale.cs             界面 DPI 缩放（96 DPI 基准，自己算）
UI/TouchStepper.cs        触屏用的 [− 数值 +] 步进控件
UI/TouchChoice.cs         触屏用的二选一按钮组（低年级 / 高年级）
Assets/app.ico            程序图标：exe、任务栏、窗口、托盘共用
App/
  AppConfig.cs            配置（kering.config.json）
  GradeSchemes.cs         低年级 / 高年级两套作息时间表（⚠ 低年级是占位值，待替换）
  AppPaths.cs             路径：配置、日志、音频都在 exe 同目录
  Logger.cs               按天滚动的文本日志
  AutoStart.cs            HKCU\Run 开机自启
  Scheduler.cs            1 秒轮询调度，按系统时钟比对打铃点
  SelfTest.cs             --selftest 自检
  Audio/
    AudioController.cs    系统音量读取 / 临时提升 / 原样恢复
    Announcer.cs          提示音 + TTS 播报
    BellTone.cs           生成占位提示音 audio\ding.wav
  Schedule/
    Model.cs              Period / CourseEntry / WeekSchedule
    ScheduleSource.cs     IScheduleSource + 本地文件实现
    SampleSchedule.cs     演示用的中学周课表
    ReminderPlanner.cs    课表 → 打铃点
```

## 已实现的约定

| 约定 | 实现位置 |
| --- | --- |
| 每节课开始前 **7 分钟**提醒 | `AppConfig.RemindAheadMinutes`（默认 7，可改） |
| 播报文案：下节课 + 课程名 + 请同学们做好课前准备 | `AppConfig.AnnouncePrefix / AnnounceSuffix` |
| 播报前把系统音量临时提到设定值，**播完恢复原值（含静音状态）** | `Announcer` + `AudioController`，恢复写在 `finally` |
| 正在上的课标红、下一个提醒点标绿 | `UI/MainForm.cs` → `UpdateHighlights` |
| 关窗不退出，收进托盘；托盘菜单含"更新课表" | `UI/MainForm.cs` |
| 开机自启（HKCU\Run），默认开启，启动时自动对齐注册表 | `App/AutoStart.cs` |
| 设置对话框：开机自启 + 提前分钟 + 播报音量 + 刷新间隔，改完立即生效 | `UI/SettingsForm.cs` |
| 界面 DPI 缩放（96 DPI 为基准，自己算，不用 WinForms 自动缩放） | `UI/UiScale.cs` |
| 窗口默认尺寸按课表内容计算，行高自适应填满，不留空白 | `UI/MainForm.cs` → `FitWindowToContent` / `FillRows` |
| 上下午分隔色带：默认插在第 4 节后，`MorningSplitAfterPeriod` 可改，填 0 不分割 | `UI/MainForm.cs` → `AddSplitBand` |
| 周六周日无课程数据时自动隐藏，有课则显示（每次更新课表重新判定） | `UI/MainForm.cs` → `HasWeekendCourses` |
| 窗口宽度跟着可见天数走：列数变了窗口就跟着收窄/变宽，列宽本身不变 | `UI/MainForm.cs` → `ApplyContentWidth` |
| 作息方案：设置里选低年级/高年级，默认高年级；时刻以方案表为准，切换后立即重算打铃点 | `App/GradeSchemes.cs` + `UI/MainForm.cs` → `ApplyGradeScheme` |
| 静音开关：工具栏按钮 + 托盘菜单，生效期间不出声；只影响本次运行，重启恢复 | `UI/MainForm.cs` → `ToggleMute` |
| 单实例：Global\ 命名锁（整机唯一）+ 命名事件唤出已有窗口；拿不到全局权限时退回本会话锁 | `Program.cs` → `AcquireMutex` / `SignalExistingInstance` |
| 单实例：重复双击会激活已有窗口 | `Program.cs` + `KeRing.ShowWindow` 事件 |
| 错过的打铃点不补播，只记日志 | `Scheduler.Rebuild` |

**明确不做**（评审时已排除）：防睡眠、漏播告警、数据过期保护、上课铃/下课铃、手动打铃、
全屏大屏视图、多铃型。

## 接入正式数据接口

现在走的是本地文件（`schedule.json`，首次运行自动生成演示数据）。

正式接入时只需：

1. 实现一个 `IScheduleSource`（例如 `HttpScheduleSource`），把"取数 + 解析"两件事都放在里面；
2. 在 `UI/MainForm.RefreshSchedule` 里换成新的实现；
3. 其余代码（打铃点生成、调度、播报、界面）不用动。

配置里已经预留了 `ScheduleApiUrl` 字段。

注意：接口只要给出"星期几、第几节、上什么课"，**上下课时刻由 `App/GradeSchemes.cs` 里的作息方案表决定**，
数据里即使带了 start/end 也会被覆盖（见需求文档 F25）。

## 交付与打包

.NET Framework 没有官方单文件发布，交付形态是**一个文件夹**：

```
dotnet build -c Release
拷贝 bin\Release\net472\ 整个目录
```

首次运行会就地生成 `kering.config.json`、`schedule.json`、`audio\ding.wav`、`logs\`。

## 首次部署到教室机器

1. 检查 .NET Framework 版本：

   ```powershell
   (Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full' -Name Release).Release
   ```

   461808 及以上是 4.7.2，528040 是 4.8。报错或数值偏低就装一次 4.7.2 离线包。

2. 拷贝文件夹，双击 `KeRing.exe`。
3. 跑一次 `KeRing.exe --selftest` 确认音频设备和中文音色正常。
4. 确认目标机**已开启自动登录**（否则 `HKCU\Run` 自启项在登录前不会执行）。
