# 智能课表打铃（KeRing）

教室一体机用的打铃程序：读课表，在每节课开始前 7 分钟播报「下节课，×××，请同学们做好课前准备」。

## 特性

- 免安装：拷一个文件夹过去双击就能跑，目标机不需要装运行时
- 开机自启、托盘常驻、关窗不退出；反复双击只会有一个实例
- 周课表界面：正在上的课标红、下一个提醒点标绿；上下午之间有一条深蓝分隔带
- 周六周日没有课时自动隐藏，窗口宽度跟着收窄
- 作息方案（低年级 / 高年级）可选，两套时间互不影响
- 播报前把系统音量临时提到设定值，播完原样恢复（含静音状态）
- 静音开关、手动更新课表、手动测试播报

## 编译运行

需要 .NET Framework 4.7.2 与 .NET SDK（或 Visual Studio）。

```
dotnet build -c Release
bin\Release\net472\KeRing.exe
```

## 命令行工具

```
KeRing.exe --selftest       # 不带界面自检：配置、课表、打铃点、音频设备、中文音色
KeRing.exe --say 语文        # 只播报一次，用来在目标机上确认真的能出声
```

## 说明

- 目标框架是 .NET Framework 4.7.2（Win10 1803 以后和 Win11 自带，Win7 需装一次），不是 .NET 8/10
- 上下课时刻由程序内置的作息方案表决定，课表数据只提供「星期几、第几节、上什么课」
- 界面按 96 DPI 设计，高 DPI 屏上自行缩放
