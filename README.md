# 智能课表打铃（KeRing）

教室一体机用的打铃程序：读课表，在每节课开始前 7 分钟播报「下节课，×××，请同学们做好课前准备」。

## 怎么用

**交付物就是一个 exe**（约 964 KB，依赖和铃声都打包在里面）：

```
dist\KeRing.exe
```

拷到目标机器任意目录，双击即可。目标机不用装运行时——Win10 1803 以后和 Win11 自带
.NET Framework 4.7.2。程序运行期间**不会在自己的目录里产生任何文件**。

**第一次打开会问你"给哪个班打铃"**，选一次就记住了，以后开机不用再选；想换班在设置里改。

## 特性

- 班级选择：课表来自数据源的**全校课表**，这台机器只认一个班，首次运行选一次即可
- 周课表界面：正在上的课标红、下一个提醒点标绿，上下午之间有深蓝分隔带
- 周六周日没有课时自动隐藏，窗口宽度跟着收窄
- 作息方案（低年级 / 高年级）可选，两套上下课时间互不影响
- 每节课前 7 分钟播报：提示音 + 语音
- 播报前把系统音量临时提到设定值，播完原样恢复（含静音状态）
- 托盘常驻、关窗不退出、开机自启；反复双击只会有一个实例
- 静音开关、手动更新课表、手动测试播报

## 运行时会生成什么

全部在数据目录 `C:\ProgramData\KeRing\`，exe 旁边不写任何东西：

| 文件 | 说明 |
| --- | --- |
| `kering.config.json` | 配置（首次运行生成），界面上改设置会写这里 |
| `logs\日期.log` | 日志，保留 30 天自动清理 |
| `schedule.json` | 演示用的课表数据（接入正式接口后不需要） |
| `audio\ding.wav` | 可选：现场替换的铃声 |

如果 `ProgramData` 不可写，会自动退到 `%LocalAppData%\KeRing`，日志里会写明。

## 换铃声

- **所有机器**：替换 `Assets\bell.wav` 后重新编译（母本会内嵌进 exe）
- **单台机器**：把 `ding.wav`（wav 或 mp3 都行）放到那台机器的 `C:\ProgramData\KeRing\audio\`，
  程序优先用它

## 命令行工具

```
KeRing.exe --selftest       # 无界面自检：配置、课表、打铃点、音频设备、中文音色、铃声、自启
KeRing.exe --say 语文        # 只播报一次，用来在目标机上确认真的能出声
```

自检返回码 = 问题数，0 表示全过。**部署到新机器后建议先跑一次**。

## 开发

```
dotnet build -c Release
```

需要 .NET SDK（本机 9.0.101）与目标框架 .NET Framework 4.7.2 的引用程序集（由 NuGet 包提供）。
不需要 Visual Studio——界面全部用代码构建，没有设计器文件。
